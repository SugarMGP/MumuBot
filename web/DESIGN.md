# MumuBot 管理后台视觉规范

这份规范约束 `web/src` 下的后台界面，目标是让总览、表格、表单、详情、瓦片和长文在**同一套层级、尺度和密度语言**里工作，而不是把所有页面压成同一种排版。

## 参考

不重新发明设计语言，直接借用成熟规范中适合后台的部分：

- [Material Design 3 — Type scale](https://m3.material.io/styles/typography/type-scale-tokens)：用“角色”而不是“字号”描述文字，标题、正文、标签各有稳定用途。
- [IBM Carbon — Spacing](https://carbondesignsystem.com/elements/spacing/overview/)：4/8/12/16/24/32 的间距台阶，以及 productive / expressive 两种密度思路。
- [GitHub Primer — Size](https://primer.style/foundations/primitives/size)：数据表格使用紧凑字号、12/14/16 的字阶和 4px 基础网格。
- [Apple Human Interface Guidelines — Typography](https://developer.apple.com/design/human-interface-guidelines/typography)：通过字号、字重和留白建立层级，不用装饰制造层级。
- [Tailwind CSS — Font Size](https://tailwindcss.com/docs/font-size)：把字号、行高、字重组合成可复用的语义类。

本项目的品牌色、侧栏、圆角和流式字号继续沿用 `styles.css`，只把“什么时候用哪一档”固定下来。

## 基本原则

1. **先定角色，再定数值**：页面标题、卡片标题、正文、说明、标签、数字各有唯一角色；不要因为“看起来小一点”随手改字号。
2. **两档密度，不是一档**：内容卡用标准密度，筛选/工具栏/导航列表用紧凑密度，指标卡和图片瓦片用瓦片密度。场景不同，密度可以不同；同一场景内必须一致。
3. **4px 台阶**：所有间距落在 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 上。页面区块 24；卡片内块 16；紧凑块 12；图标与文字 8。
4. **字重只用三档**：正文 400，标签/控件/表头/徽标 500，标题/指标数字 600。不要用 700 制造强调。
5. **文字层级三层**：正文用 `foreground`；说明、辅助用 `muted-foreground`；更弱的提示才叠加 `/75`、`/60`、`/45`。不要再出现 `/70`、`/80`、`/85`。
6. **一个卡片只有一种内边距**：标准 20、紧凑 16、瓦片 12。卡片内部不要再套一个不同内边距的“假卡片”。
7. **流式尺度只作用于字号和页面边距**：1000px 横屏取下限，1600px 及以上回到设计值；组件内部间距仍按 4px 台阶。

## 尺度

### 间距

| 令牌 | 值 | 用途 |
|------|----|------|
| `--space-1` | 4px | 图标与文字、徽标内部 |
| `--space-2` | 8px | 紧凑行内元素、按钮组 |
| `--space-3` | 12px | 紧凑面板内块、表单项之间（紧凑） |
| `--space-4` | 16px | 标准卡片内块、表单栅格、卡片栅格 |
| `--space-5` | 20px | 标准卡片内边距 |
| `--space-6` | 24px | 页面区块间距、详情主栏与侧栏 |
| `--space-8` | 32px | 页面左右留白上限、特殊留白 |
| `--space-12` | 48px | 空状态、hero 类留白 |

页面根节点统一 `space-y-6`。同一张卡片内部使用 `space-y-4`（标准）或 `space-y-3`（紧凑）；不要再出现 `space-y-5` 这种半档。

### 字号与字重

| 角色 | 字号 / 行高 | 字重 | 用途 |
|------|-------------|------|------|
| 页面标题 | 28 / 1.15 | 600 | `PageHeader`、详情页 h1 |
| 卡片标题 | 18 / 1.3 | 600 | 标准内容卡、详情卡 |
| 紧凑标题 | 14 / 1.4 | 600 | 筛选面板、导航列表、内嵌面板 |
| 小节标签 | 12 / 1.55 | 600 | 详情卡里的“关键词 / 未完成事项”等分组 |
| 正文 | 14 / 1.65 | 400 | 卡片正文、表格内容、表单值 |
| 标签 | 14 / 1.4 | 500 | 表单 label、字段名 |
| 说明 | 12 / 1.55 | 400 | 卡片副标题、字段提示、元信息 |
| 表头 | 12 / 1.4 | 500 | 表格列名 |
| 指标数字 | 24 / 1.1 | 600 | 总览大数字，使用等宽数字 |
| 紧凑指标 | 20 / 1.1 | 600 | 小卡片、成员统计 |
| 按钮 | 14 / 1.2 | 500 | 主/次按钮、文字按钮 |
| 徽标 | 12 / 1.2 | 500 | 状态、计数、标签 |
| 代码/ID | 12 / 1.5 | 400 | 哈希、QQ、时间、cron，等宽 |
| 长文 | 14 / 1.8 | 400 | 日记、记忆正文、摘要长文（可读性优先） |

- 中文标题不要加字间距；英文/数字标题可保留 `-0.01em` 的紧排。
- 指标数字、QQ、时间、哈希统一 `admin-number`（等宽、tabular）。
- 长文允许比 UI 正文更松的行高，但不能同时再放大字号；`admin-prose` 为唯一长文角色。

### 圆角与阴影

| 对象 | 圆角 |
|------|------|
| 页面卡片 | 18px（`rounded-xl` / `--admin-card-radius`） |
| 卡片内子块、输入框、按钮、标签页 | 12px（`--admin-inner-radius` / `rounded-lg`） |
| 徽标、小标签 | 8px（`rounded-md`） |
| 头像 | 圆形 |

卡片阴影只用 `--card-shadow`；hover 只用 `--card-shadow-hover`。不要在单个页面重新定义阴影。

## 密度模式

### 标准（内容卡、表单、详情）

- 内边距 20px，标题 18/600，说明 12/400，内部块间距 16px。
- 页内卡片之间 24px；卡片栅格 16px。
- 表格卡片、详情卡、设置卡、日志卡都属于这一档。

### 紧凑（筛选、工具栏、导航列表）

- 内边距 16px，标题 14/600，内部块间距 12px。
- 用于 `FilterPanel`、`SortToolbar`、会话列表、人格预设列表、日志内联工具栏。
- 不把紧凑面板和标准内容卡混在同一层级；紧凑面板只承担“筛选/导航/工具”职责。

### 瓦片（指标卡、贴纸、内嵌记录）

- 内边距 12px，标题 14/600，元信息 12/400。
- 用于总览指标、贴纸格、情感记录等小卡。瓦片内不再放第二个带边框的卡片。

### 长文（日记、记忆正文、摘要）

- 内边距 20px，正文 14/1.8，标题仍按卡片标题。
- 只用于阅读型内容；不要把表单或表格套进长文角色。

### 控制台（日志）

- 继续使用 12px 等宽；工具栏 12px 内边距；行高紧凑。
- 这是一块“数据密集”区域，不强行套标准卡片正文尺寸。

## 组件规则

### 页面头

- 标题 28/600；副标题 14/1.65、`muted-foreground`、最大宽度 3xl。
- 带标签页的页面（设置/系统/模型/MCP）使用一行 `PageHeader + Tabs`，允许 `flex-wrap`；1000px 下换行不挤压标题。
- 操作按钮靠右，间距 8px；不要在页面头放两个以上主按钮。

### 卡片

- 有标题/说明/操作时用 `SectionCard`；只有内容时用 `Card` + 标准内边距。
- 标准卡标题 18/600，说明 12/400；标题与内容间距 16px；标题与说明间距 4px。
- 卡片内子块使用 12px 圆角、12px 内边距；不要再套 18px 圆角的大卡。
- 卡片之间用 24px（页面）或 16px（栅格）；不要用 20px 这种半档。

### 筛选与工具栏

- 统一用 `FilterPanel`；内边距 16；表单栅格 12。面板默认不重复“筛选”标题，只有需要说明范围时才传入可选标题。
- 字段统一 `Field`：label 14/500，控件高 36，提示 12/400。
- 工具栏（排序、计数、动作）放在表格卡片顶部或页面中，不单独做成“半张卡”。

### 表格

- 表头 12/500、`muted-foreground`；单元格 14/400；行内边距 12px；行 hover 用 `--row-hover`。
- 主字段可用 500 字重，次字段 400；不要让整列都加粗。
- 表格横向内边距随卡片内边距；第一个/最后一个单元格不要额外贴边。

### 表单

- 两列栅格在 1000px 以上启用；只有短数字可以三列。
- 字段之间 16px；label 与控件 6px；提示与控件 6px。
- 主按钮在表单底部，左对齐；恢复默认用 ghost/outline。
- 设置卡内的保存按钮行使用上边框 + 16px 上间距，不要再加一块背景。

### 列表与记录

- 记录卡使用标准卡：标题 18/600，元信息 12/400，行块 12-16px。
- 导航型列表使用紧凑面板：标题 14/600，条目 12px 内边距；当前项用主色底 + 左侧标记。
- 成员卡、话题卡、贴纸卡分别属于记录卡/记录卡/瓦片，不要互相套用内边距。

### 按钮、徽标、标签页

- 按钮统一 12px 圆角、14/500；默认高 36，小号 32，极小 28。
- 徽标 12/500、8px 圆角；状态色只表达状态，不表达层级。
- 标签页使用同一分段控件（`rounded-lg`、1px 边框、激活主色）；不要手写第二套。

### 空状态、分页、弹层

- 空状态：虚线边框、上下 48px、正文 14、可选动作按钮。
- 分页：顶部 24px 间距、1px 上边框、14/400；当前页用主色圆角块。
- 弹层标题 18/600；正文 14/1.65；底部按钮右对齐，间距 8px。

## 禁止事项

- 不要用 `p-6`、`space-y-5`、`gap-5` 这类半档值表达“我觉得松一点”。
- 不要在同一页混用 16/18/20 三种卡片标题。
- 不要把标准内容卡做成 12px 内边距，也不要把筛选面板做成 20px。
- 不要用 `/70`、`/80`、`/85` 的文字透明度。
- 不要用 `font-bold`；强调靠字号、颜色和留白。
- 不要给表格行加斑马纹或每行卡片阴影。
- 不要在卡片里再套一个同尺寸边框卡片；内嵌块只到 12px 圆角、12px 内边距。

## 动效边界

- 共用弹层：右侧编辑面板 200ms、中央确认框 160ms，使用 `--admin-motion-ease` 与 `--admin-motion-panel` / `--admin-motion-quick`；关闭使用普通 ease-in。只动画遮罩和弹层本身，不缩放表单。
- 页内标签：设置分区、人格内容标签只让选中下划线平滑移动，160–200ms；不动长表单整块，不使用胶囊拉伸或逐字段进场。
- 受控展开：MCP 高级设置 140–180ms 展开高度，保留 `aria-expanded`；其他长列表、日志和图表不做高度动画。
- 可点击卡片只补颜色、边框、浅阴影的 120–160ms 过渡，不给信息卡或表格整块抬升。
- `prefers-reduced-motion` 下取消新增位移、缩放和高度过渡；CSS 与 Motion 各自处理，不能只依赖全局 0.01ms 规则。
