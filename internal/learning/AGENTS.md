# AGENTS

本目录负责持续学习群文化：黑话、风格卡片和成员画像。它不是长期记忆写入宿主。

## 入口与职责

- `learner.go`：学习循环、审核流程、黑话提取、风格卡片提取、成员画像提取。
- learner 由 agent 启动，但读取范围由 memory/topic 的处理状态决定。
- 黑话和风格候选进入后台审核；成员画像按证据事务写入，不伪造成稳定长期记忆。

## 消费边界

- 只能消费话题系统已处理完成的消息。
- 只读取 learner 连续可消费的已处理前缀，不全量扫描未判定历史。
- 群文化和成员画像分别使用 `culture`、`member_profile` 两个最小游标，任一路失败都不能伪装成已处理。
- 提取输入只使用原始文本；原始文本为空的消息跳过。
- 不和话题摘要重复扫描同一批未判定消息。

## 产物边界

- 黑话：群内特殊说法、梗、固定表达。
- 风格卡片：开放的 `situation + expression`，描述群聊语气、表达习惯和互动风格。
- 成员画像：按全局 `user_id` 维护 `alias`、`speaking`、`interest`、`phrase` 等带证据特征，不恢复 Activity/Intimacy 数值模型。
- 不在 learner 中新增自动长期记忆写入、话题归属或摘要刷新逻辑。

## 修改注意

- 证据不足或模型不确定时保持待审核或跳过，不强行通过。
- 候选提取和自动审核保持两个独立结构化步骤，不在同一事务步骤里边提取边审核。
- 学习水位推进必须和实际处理结果一致，不能跳过失败消息制造“已学习”状态。
- `batch_size` 必须大于等于 `min_msg_count`；不要引入会让同一批消息永久停滞的合法配置。
- 后台审核文案要给使用者看，避免暴露模型字段名和内部流程。
