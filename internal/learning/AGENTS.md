# AGENTS

本目录运行唯一后台 Memory Agent，同一上下文完成话题归属、摘要、稳定知识与群文化维护。

- learner.go 负责单群冷却、批次/等待条件和群间轮转；调查工具及 finish 在 investigate.go。
- 执行器复用 Eino ReAct，不手写模型/工具循环；Memory Agent 直接使用配置中的 Eino MaxStep，默认25。
- 同群一个 learning_states 水位，消息直接来自原文，不等待预先 assignment。
- 启动、积压恢复、工具续轮和向量补全均遵守限速；不立即循环排空某一个群。
- 通常直接提交，确需历史才调查；失败保留进度。
- finishMemoryBatch 原子提交话题、摘要、知识、证据和进度；每条本批可用消息恰好分配一次。
- 旧话题归属不可改写；重新扫描旧库时，不用较早批次覆盖已有较新摘要。
- 群文化 enabled 开关只禁止新增术语、表达、别名，不关闭话题或稳定知识整理。
- 只使用原始文本。机器人消息参与对话理解，但不作为群友事实或群文化的独立证明。
- 不提取成员常用词、泛化风格；不凭时间顺序或缩写猜词源。知识与关系都需要自己的完整证据。
- 验证覆盖请求间隔、取消等待和事务回滚，不为每个函数增加独立测试框架。
