# AGENTS

本目录负责持续学习群文化：黑话、风格卡片和成员画像。它不是长期记忆写入宿主。

## 入口与职责

- `learner.go`：学习循环、审核流程、黑话提取、风格卡片提取、成员画像提取。
- learner 由 agent 启动，但读取范围由 memory/topic 的处理状态决定。
- 学习结果面向后台审核，不直接伪造成稳定长期记忆。

## 消费边界

- 只能消费话题系统已处理完成的消息。
- 只读取 learner 连续可消费的已处理前缀，不全量扫描未判定历史。
- 提取输入只使用原始文本；原始文本为空的消息跳过。
- 不和话题摘要重复扫描同一批未判定消息。

## 产物边界

- 黑话：群内特殊说法、梗、固定表达。
- 风格卡片：群聊语气、表达习惯、互动风格。
- 成员画像：按全局 `user_id` 维护成员长期特征。
- 不在 learner 中新增自动长期记忆写入、话题归属或摘要刷新逻辑。

## 修改注意

- 证据不足或模型不确定时保持待审核或跳过，不强行通过。
- 学习水位推进必须和实际处理结果一致，不能跳过失败消息制造“已学习”状态。
- 后台审核文案要给使用者看，避免暴露模型字段名和内部流程。
