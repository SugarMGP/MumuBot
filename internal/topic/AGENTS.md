# AGENTS

本目录是被动的话题读取模块，不再调用模型或启动归属、摘要、恢复 worker。

- manager.go 负责消息持久化入口和主聊天 Agent 的话题上下文；store.go 保存数据库读取和混合检索。
- 话题归属、摘要更新与知识整理统一由 internal/learning 执行，并经 memory.CommitConversation 原子提交。
- topic_summaries 不保存 claims，embedding 可以暂为空，由同一个后台调度补全；文本和最近话题读取不能依赖向量已完成。
- 固定快照限制依然成立：不能返回覆盖了上界后消息的摘要。
- 主聊天上下文优先被回复消息所属话题，再补混合检索和固定消息快照实际涉及的话题，最多3个完整话题，不无条件填满；历史参考日期来自摘要来源及展示原文，不用摘要更新时间。
- 无原文消息直接标记 no_topic，不回退到展示文本。
- 不新增前置分类调用、独立话题计数、旧结构化输出或话题开关。
